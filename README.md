# Regression Analysis: Prediction, Foundations, and Inference

**Alexis Diamond, PhD** (assisted by Claude and ChatGPT)
**Version 0.9 — August 26, 2026**

A six-chapter introduction to regression analysis built around one central idea: *regression is a prediction machine.* The book develops conditional expectations, OLS foundations, coefficient and prediction uncertainty, functional form, interpolation and extrapolation, and the connection between regression, overlap, and causal inference — with worked examples in base R throughout. A companion R notebook mirrors the book chapter by chapter so every result can be reproduced.

## Building from source

Requirements: a TeX distribution (TeX Live recommended, with `pgfplots`, `listings`, `makeidx`), R with the `rmarkdown` and `knitr` packages, and `pandoc`.

```sh
make book        # compile the PDF (pdflatex ×2 → makeindex → pdflatex ×2)
make companion   # regenerate regression_companion.R and knit the HTML
make all         # both
make check       # run the companion R script end-to-end as a smoke test
make clean       # remove LaTeX/R intermediate files
```

The pass order for the book matters: the index must be built **after** the table of contents has stabilized, so `makeindex` runs between the second and third `pdflatex` passes. `make book` (and the CI workflow) do this correctly; if you compile by hand, follow the same order or the index page numbers will be stale.
