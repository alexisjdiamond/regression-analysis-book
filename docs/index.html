Regression Analysis: Prediction, Foundations, and Inference

Alexis Diamond, PhD (assisted by Claude and ChatGPT)

Version 0.9 — August 26, 2026

A six-chapter introduction to regression built around one idea: regression is a prediction machine. The book develops conditional expectations, the technical foundations of OLS, coefficient and prediction uncertainty, functional form, interpolation and extrapolation, and the connection between regression, overlap, and causal inference — with worked base-R examples throughout. Every numerical result in the book is generated by the code shown, so everything can be reproduced.
